## Instalación

1. Desde el navegador Ingresa con tu cuenta a GitHub y abre el [repositorio](https://github.com/clubdecomputacion/lp3-taller1).

2. Abre una Terminal:

```bash
# trabaja desde tu directorio de Proyectos:
cd Proyectos

# clona tu fork del repositorio:
gh repo clone tu_usuario/lp3-taller1

# ingresa al directorio de tu repositorio:
cd lp3-taller1

# crea tu entorno virtual (venv):
python3 -m venv .venv

# activalo
source .venv/bin/activate

# instala las librerías necesarias
pip install -r requirements.txt

# abre Visual Studio Code
code .

```

3. Sigue los pasos de la [`GUIA.md`](docs/GUIA.md)
